How it works

Three detection layers produce one score from 0 to 100. Every point is shown with its reason.

1. Signatures

The SHA-256 and MD5 of the file are compared with a JSON database ({{ n_sigs }} entries). A match means a known file: score 100.

2. Rules

{{ n_rules }} YARA-style rules look for text, hex bytes and regular expressions. Each rule has a severity (high +40, medium +25, low +10) and a MITRE ATT&CK technique.

3. Heuristics (full scan)

Shannon entropy, suspicious strings, suspicious Windows API names, PE section names and entropy (packing), extension mismatch and double extensions.

Verdict

Clean below {{ suspicious_at }}, Suspicious from {{ suspicious_at }}, Malicious from {{ malicious_at }}. Malicious files can be quarantined automatically.
